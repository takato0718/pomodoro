1. プロダクト概要
1.1 プロダクト名
TubePomo（公開URL: https://takato0718.github.io/pomodoro/）

1.2 コンセプト
「3タップで爆速スタート」YouTubeの好きな音楽で集中できる、世界一シンプルなポモドーロタイマー。

1.3 ターゲットユーザー
YouTubeのLo-Fi、作業用BGM、推しの曲を聴きながら勉強・作業したい学生やエンジニア
ポモドーロテクニックを実践したい人
スマホ・PCの両方で気軽に使いたい人
1.4 提供価値
ログイン不要で即使える手軽さ
YouTubeの膨大な音楽ライブラリを活用できる
個別動画とプレイリストの両方に対応した柔軟性
2. 機能要件（MVP）
2.1 タイマー機能
2.1.1 基本機能
集中時間・休憩時間のカスタム設定

初期値：集中25分 / 休憩5分
1分単位で変更可能（1〜90分の範囲）
設定値はブラウザに自動保存
タイマーの制御

スタート / 一時停止 / リセット ボタン
残り時間の表示（MM:SS形式）
集中時間終了後、自動で休憩時間に切り替え
2.1.2 YouTube連動機能
集中時間中：集中用プレイリストを再生
休憩時間中：休憩用プレイリストを再生（集中用・休憩用は別々に登録・管理）
タイマー停止時：YouTube一時停止
モード切り替え時：離れる側の再生位置（動画IDと再生秒数）を保存し、そのモードに戻ってきたら続きから再生
2.1.3 通知機能
タイマー終了時に音で通知（ブラウザのアラート音）
将来拡張：ブラウザ通知（Notification API）
2.2 YouTube再生機能
2.2.1 URL入力・追加
入力フォーム

YouTube動画URL または プレイリストURL を入力
入力例を表示して、ユーザーをガイド
バリデーション：YouTube URLかどうかをチェック
自動判定

プレイリストURL（list=を含む）→ プレイリストとして登録
個別動画URL → 単一動画として登録
2.2.2 曲リスト管理
表示

集中用・休憩用のタブ（セグメントコントロール）で編集対象を切り替え
登録済みの動画/プレイリストを一覧表示（サムネイル付き）
各項目に「削除」ボタンを配置（削除前に確認ダイアログを表示）
プレイリストには 🎵 アイコン、動画には ♪ アイコンを表示
並び替え

「並び替え」モードに切り替え、各項目の Top / ↑ / 下 / Bottom ボタンで順番を変更
再生中の曲が並び替えられても、再生インデックスが追従してズレない
2.2.3 再生制御
基本再生

リストの最初から順番に再生
1曲（またはプレイリスト）が終わったら次へ自動遷移
最後まで再生したら最初に戻る（ループ再生）
再生エラー時は自動で次の曲へスキップし、連続エラーが上限に達したら停止してエラーメッセージを表示
プレイヤー表示

表示サイズを 小（200x200px）/ 中（画面の一定割合）/ 大（画面いっぱい）の3段階で切り替え可能
音量調整スライダー
次の曲へスキップボタン（将来拡張）
2.3 データ永続化
2.3.1 保存するデータ
タイマー設定（集中時間・休憩時間・音量）
集中用・休憩用の曲リスト（それぞれ独立して保存）
2.3.2 保存方法
LocalStorage を使用
JSON形式で、キーごとに分けて保存
LocalStorage キー：
- `pomodoro_settings`: タイマー設定
- `pomodoro_focusTracks`: 集中用の曲リスト
- `pomodoro_breakTracks`: 休憩用の曲リスト
データ構造例：
{
  "pomodoro_settings": {
    "focusTime": 25,
    "breakTime": 5,
    "volume": 50
  },
  "pomodoro_focusTracks": [
    { "uid": "xxxxxxxx-xxxx-...", "type": "video", "id": "abc123", "title": "作業用BGM" }
  ],
  "pomodoro_breakTracks": [
    { "uid": "yyyyyyyy-yyyy-...", "type": "playlist", "id": "PLxxx", "title": "Lo-Fi Mix" }
  ]
}
各曲は `crypto.randomUUID()` で生成した `uid` を持ち、削除・並び替え・再生位置の追跡に利用する
再生中の位置（再開情報）はモード切り替え時のみ一時的にメモリ上で保持し、LocalStorage には保存しない
2.3.3 注意事項
ブラウザのキャッシュクリアで消える可能性がある旨をユーザーに注記
デバイス間での同期は不可（将来拡張：ユーザー登録機能）
