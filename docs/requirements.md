1. プロダクト概要
1.1 プロダクト名
Simple YouTube Pomodoro（仮称）

1.2 コンセプト
「3タップで爆速スタート」YouTubeの好きな音楽で集中できる、世界一シンプルなポモドーロタイマー。

1.3 ターゲットユーザー
YouTubeのLo-Fi、作業用BGM、推しの曲を聴きながら勉強・作業したい学生やエンジニア
ポモドーロテクニックを実践したい人
スマホ・PCの両方で気軽に使いたい人
1.4 提供価値
ログイン不要で即使える手軽さ
YouTubeの膨大な音楽ライブラリを活用できる
個別動画とプレイリストの両方に対応した柔軟性
2. 機能要件（MVP）
2.1 タイマー機能
2.1.1 基本機能
集中時間・休憩時間のカスタム設定

初期値：集中25分 / 休憩5分
1分単位で変更可能（1〜90分の範囲）
設定値はブラウザに自動保存
タイマーの制御

スタート / 一時停止 / リセット ボタン
残り時間の表示（MM:SS形式）
集中時間終了後、自動で休憩時間に切り替え
2.1.2 YouTube連動機能
集中時間中：YouTube再生
休憩時間中：YouTube一時停止（または休憩用の曲に切り替え ※将来拡張）
タイマー停止時：YouTube一時停止
2.1.3 通知機能
タイマー終了時に音で通知（ブラウザのアラート音）
将来拡張：ブラウザ通知（Notification API）
2.2 YouTube再生機能
2.2.1 URL入力・追加
入力フォーム

YouTube動画URL または プレイリストURL を入力
入力例を表示して、ユーザーをガイド
バリデーション：YouTube URLかどうかをチェック
自動判定

プレイリストURL（list=を含む）→ プレイリストとして登録
個別動画URL → 単一動画として登録
2.2.2 曲リスト管理
表示

登録済みの動画/プレイリストを一覧表示
各項目に「削除」ボタンを配置
プレイリストには 🎵 アイコン、動画には ♪ アイコンを表示
並び替え

ドラッグ&ドロップで順番を変更可能（将来拡張）
初期MVPでは、追加順に再生
2.2.3 再生制御
基本再生

リストの最初から順番に再生
1曲（またはプレイリスト）が終わったら次へ自動遷移
最後まで再生したら最初に戻る（ループ再生）
プレイヤー表示

画面の隅に小さく表示（最低 200x200px）
音量調整スライダー
次の曲へスキップボタン（将来拡張）
2.3 データ永続化
2.3.1 保存するデータ
タイマー設定（集中時間・休憩時間）
登録済みの動画/プレイリストリスト
音量設定
2.3.2 保存方法
LocalStorage を使用
JSON形式でデータを保存
データ構造例：
{
  "settings": {
    "focusTime": 25,
    "breakTime": 5,
    "volume": 50
  },
  "tracks": [
    { "type": "video", "id": "abc123", "title": "作業用BGM" },
    { "type": "playlist", "id": "PLxxx", "title": "Lo-Fi Mix" }
  ]
}
2.3.3 注意事項
ブラウザのキャッシュクリアで消える可能性がある旨をユーザーに注記
デバイス間での同期は不可（将来拡張：ユーザー登録機能）
2.4 ユーザー管理
2.4.1 MVP
ログイン機能なし
アクセスしてすぐに使える手軽さを最優先
2.4.2 将来拡張
Firebase Authentication または Supabase でのユーザー登録
設定のクラウド同期
3. 非機能要件

3.2 互換性

Chrome（最新版）
