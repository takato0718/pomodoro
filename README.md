# Simple YouTube Pomodoro

YouTubeの音楽と連動したポモドーロタイマーアプリ。

## 技術スタック

- React (Vite)
- Tailwind CSS
- react-youtube
- LocalStorage

## セットアップ

```bash
npm install
npm run dev
```

## スクリプト

| コマンド | 説明 |
|---------|------|
| `npm run dev` | 開発サーバー起動 |
| `npm run build` | 本番ビルド |
| `npm run lint` | ESLint 実行 |
| `npm run preview` | ビルド結果のプレビュー |
